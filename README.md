# Conversor CSV para SQL
Este é um simples script em Python que converte um arquivo CSV para um banco de dados SQLite.

### Funcionalidades
  - Lê um arquivo CSV e cria uma tabela no banco de dados SQLite
  - Insere os dados do CSV na tabela criada
  - Salva as alterações no banco de dados
    
### Requisitos
  - Python 3.x
  - Biblioteca csv
  - Biblioteca sqlite3
    
### Uso
  - Substitua 'dados.csv' pelo nome do seu arquivo CSV
  - Substitua 'meu_banco.db' pelo nome do seu banco de dados SQLite
  - Execute o script usando python script.py
    
## Observações
Certifique-se de criar um banco de dados SQLite antes de executar o script

O script assume que o arquivo CSV tem as colunas coluna1, coluna2 e coluna3
